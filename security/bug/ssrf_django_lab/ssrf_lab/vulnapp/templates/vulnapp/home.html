SSRF Training Lab

Four intentionally vulnerable endpoints, one exercise per SSRF anti-pattern. Attack them, then read views.py to see exactly why each one broke.

LEVEL 1 Naive SSRF
/level1/stock-check/ — no validation at all.
LEVEL 2 Blacklist-based filter (bypassable)
/level2/webhook-test/ — blocks literal "localhost"/"127.0.0.1" strings.
LEVEL 3 Whitelist-based filter (bypassable)
/level3/import-avatar/ — naive startswith() domain check.
LEVEL 4 Blind SSRF + metadata escalation
/level4/export-report/ — POST only, response never reflects fetch result.
Requires the simulated internal service (internal_service.py) running on port 9000.

See README.md for the full exploitation walkthrough for every level.
